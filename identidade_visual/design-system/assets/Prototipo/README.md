# Protótipo

A Figura 1 do manual de padronização: o protótipo de dashboard de performance aprovado como estudo de caso de portfólio.

`dashboard-performance.png` — referência de composição. Mostra a regra 60/30/10 aplicada numa tela real: fundo `deep-violet-space`, dois cartões de KPI em `deep-imperial-purple` com borda de série, barras horizontais em cores de dados alternadas, linha de tendência em `neon-pink` com rótulo de valor em cada ponto, grade em `indigo` e nota de fonte no rodapé.

Use a imagem para conferir proporção, folga entre elementos e posição de rótulo. Os valores de cor, espaçamento e raio saem de `tokens.json`, não da imagem — a escala de espaçamento de 8px e os raios deste sistema foram lidos daqui e estão marcados como derivados.

Não publique a imagem como peça final: ela é material de referência interna do sistema.
